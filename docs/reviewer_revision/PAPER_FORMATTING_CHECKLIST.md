# Manuscript Structure and Formatting Checklist

## Required section order

The manuscript source is organized in this order:

1. **I. Abstract**
2. **II. Introduction**
3. **III. Related Works**
4. **IV. Methods**
5. **V. Results and Discussion**
6. **VI. Conclusion**
7. **VII. Reference**

The reference list currently contains 16 entries, above the minimum of 15. Each entry is cited in the manuscript body. Bibliographic details should receive a final cross-check against the target conference's preferred reference style before submission.

## Five-page target

- Target **five pages**, using the conference's official template if available; do not shrink the font or margins below template requirements to force the page count.
- Prefer a standard two-column conference layout if that is the venue's required format.
- Keep all result tables legible. If the template causes the paper to exceed five pages, tighten repeated prose and combine redundant explanations before removing necessary methodology, results, limitations, or citations.
- The Markdown source does not itself guarantee a five-page rendered result. The final page count must be checked after importing the content into the official template and exporting to PDF.
- Keep the abstract, table values, conclusion, and reviewer response synchronized with the latest checked result files.

## Scientific integrity checks

- Describe the study as simulation-based; do not imply measured-vehicle validation.
- Retain the current 39-event protocol and do not restore the unreconciled historical approximately 97% claim.
- State that the sensor noise is illustrative and that exact noise/quantization settings and hardware benchmarks are not yet verified in the manuscript source.
- Distinguish five-seed regression variability from run-cluster bootstrap uncertainty.
- State that the current two-degree-of-freedom lateral model does not validate rollover or load-transfer-ratio claims.
- Do not describe the Hybrid model as a validated vehicle controller or claim sufficient driver reaction time from the observed lead times.
